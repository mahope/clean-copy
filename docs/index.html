Clean Copy

Copy selected text as clean text or Markdown — right from your browser. No formatting junk, ever.

Download v1.0.0 (.zip) View source on GitHub

🧹 Clean text

Strips fonts, colors and hidden markup. What you paste is plain, readable text.

📝 Markdown

Headings, links, lists and bold convert to proper Markdown automatically.

🔒 Private by design

Runs entirely on your device. No accounts, no tracking, no servers.

Install in 30 seconds

  1. Download the zip and unzip it.
  2. Open chrome://extensions and enable Developer mode (top-right toggle).
  3. Click Load unpacked and pick the unzipped clean-copy folder.
  4. Select any text → right-click → Clean Copy. Done.

Why?

Pasting from the web drags along invisible styles, smart quotes, broken line breaks and 40-line HTML. Clean Copy gives you exactly what you selected — as plain text or ready-to-use Markdown. Built for developers, writers, students and researchers.
